# Instructions to build the Dockerfile and get the resulting image:

## Build the Dockerfile:

### 1. Download the zip file
### 2. Create a Dockerfile within the app directory using the terminal or an IDE
### 3. Check that the Dockerfile does not have any file extension like .txt
### 4. Copy the contents of the Dockerfile into the dockerfile

## Get the resulting image:

### 1. Type the command "docker build -t image name" into the terminal (replace image name with a name for the image)
### 2. Start an App Container by typing this command "docker run -dp 3000:3000 image name" into the terminal (replace image name with a name for the image)
### 3. Open your web browser to http://localhost:3000
### 4. The resulting image will appear into your screen
