# Instructions to build the Dockerfile and get the resulting image:

## Build the Dockerfile:

### Download the zip file
### Create a Dockerfile within the app directory using the terminal or an IDE
### Check that the Dockerfile does not have any file extension like .txt
### Copy the contents of the Dockerfile into the dockerfile

## Get the resulting image:

### Type the command "docker build -t image name" into the terminal (replace image name with a name for the image)
### Start an App Container by typing this command "docker run -dp 3000:3000 image name" into the terminal (replace image name with a name for the image)
### Open your web browser to http://localhost:3000
### The resulting image will appear into the screen
